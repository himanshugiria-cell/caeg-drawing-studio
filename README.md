# CAEG Drawing Studio

Teaching website for Computer Aided Engineering Graphics, PIET Jaipur, Semester I 2026–27.

Prepared by Himanshu Giria. Includes classroom slides, student notes and interactive construction lessons through Experiment 10.

## Publish with GitHub Pages

In repository Settings → Pages, select Deploy from a branch, main, and / (root). No build command or package installation is needed.

## Updating lessons

Edit the HTML, CSS and JavaScript files and replace the relevant downloads in materials/. Keep relative links so the website works under a GitHub project URL. Lesson URLs use .html on GitHub Pages.

## Local preview

Run `python3 -m http.server 8000` from this directory and open http://localhost:8000.
